\abtitel{2.1}{Objektbeziehungen -- Klassen als Datentypen}

Verschiedene Objekte eines Systems können miteinander kommunizieren:
\begin{itemize}
\item Ein Objekt \luecke[12cm]
\item Ein Objekt \luecke[12cm]
\end{itemize}
Dafür müssen sie einander jedoch „kennen“.

\begin{merke}[Referenzattribute]
Die Attribute der Klasse \code{Flagge} sind Objekte einer anderen Klasse (hier \code{Rechteck}). Als Datentyp haben sie ihre Klasse. Der Wert des Attributs ist eine \luecke (Verweis auf den Speicherplatz) auf das enthaltene Objekt. Deshalb nennt man solche Attribute auch \luecke.
\end{merke}
