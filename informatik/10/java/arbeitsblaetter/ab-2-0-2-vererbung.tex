\begin{merke}[Vererbungshierarchie, Ober- und Unterklassen]
Bei der Vererbung gibt es Unter- und Oberklassen. Eine \luecke besitzt automatisch alle Attribute und Methoden der \luecke. Es werden zwei Richtungen unterschieden: Wird eine Unterklasse erstellt, so spricht man von einer \luecke der Oberklasse. Umgekehrt ist die Oberklasse eine \luecke der Unterklasse.

Ist eine Unterklasse gleichzeitig Oberklasse einer weiteren Klasse, spricht man von \textbf{mehrstufiger Vererbung}; es entsteht eine \luecke.

Konstruktoren werden \luecke[2.5cm] vererbt. Die Unterklasse ruft den Konstruktor der Oberklasse mit \luecke[2.5cm] auf.
\end{merke}

\begin{merke}[Vererbung und Überschreiben]
Definiert man eine Methode in der Unterklasse erneut (gleicher Name, gleiche Parameter, gleicher Rückgabetyp), so wird die ursprüngliche Methode \luecke. Sie hat in der Unterklasse eine \textbf{andere} Funktionsweise.

Die Annotation \code{@Override} vor der Methode sagt dem Compiler: Diese Methode überschreibt eine gleichnamige Methode der Oberklasse. Gibt es diese nicht (z.\,B. Tippfehler), meldet der Compiler einen \luecke[2.5cm]. Ohne \code{@Override} entsteht stattdessen stillschweigend \luecke[4cm].
\end{merke}
