\begin{merke}[Bedingungen an Elemente im Array stellen]
Die Kombination von \luecke[4.5cm] und \luecke[4.5cm] kann genutzt werden, um Bedingungen an die Elemente eines Arrays zu stellen: Eine Anweisung wird nur ausgeführt, wenn die Bedingung für das aktuelle Element erfüllt ist. So lassen sich etwa nur die bisher torlosen Spieler ausgeben.
\end{merke}
