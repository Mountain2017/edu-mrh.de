2.6 Arrays durchsuchen

Objektorientierte Programmierung mit Java · Informatik 10 (NTG) · 2 Stunden

Du kannst: ein Array von Objekten mit einer Schleife durchlaufen, Werte aufsummieren und nur die Elemente behandeln, die eine Bedingung erfüllen.

EinstiegStatistik fürs Schulturnier

Beim Schul-Fußballturnier soll es Statistiken geben. Jede Spielerin und jeder Spieler hat die Zahl der bisher erzielten Tore. Die Personen einer Mannschaft stecken in einem Array spielerliste.

Beschreibe auf dem Blatt in Worten (noch kein Java): Wie berechnet man mithilfe von spielerliste, wie viele Tore die Mannschaft insgesamt geschossen hat? Überlegt zu zweit, welche weiteren Statistiken möglich wären.

Denkanstoß

Eine Hilfsvariable int summe = 0; vor der Schleife. In der Schleife kommt bei jedem Durchlauf ein Wert dazu. Nach der Schleife: return summe;.

📝

FesthaltenBedingungen an Elemente stellen

Nicht immer sollen alle Elemente behandelt werden. Sollen nur die torlosen Spieler ausgegeben werden, kombinierst du die Schleife mit einer bedingten Anweisung: Die Anweisung im Schleifenrumpf läuft nur, wenn die Bedingung für das aktuelle Element gilt.

Fülle den Merkkasten auf dem Blatt und übertrage den Lückencode ins Hauptprogramm (TODO 2). Fülle erst die Lücken auf dem Blatt, dann im Code.

UntersuchenAufgabe 2: Projekt Sportarten

Jetzt zwei Arrays ineinander: Die Mannschaft hat ein Array von Spielern, und jeder Spieler hat ein Array seiner Sportarten (String[]).

  1. Schreibe in Spieler die Methode ersetzeSportartTennis(): Überall, wo „Tennis“ steht, soll „Squash“ stehen (TODO 1). Teste sie im Hauptprogramm an einem Spieler.
  2. Schreibe spieltSportart(String sportart) (TODO 2). Welcher Rückgabetyp ist sinnvoll, wenn die Antwort „ja“ oder „nein“ ist? Gib im Hauptprogramm für jeden Spieler aus, ob er Tennis spielt.
Stolperstein: Zwei Texte vergleicht man in Java nicht mit ==, sondern mit sportarten[i].equals("Tennis"). Mit == kann es sein, dass dein Vergleich zufällig klappt und woanders nicht.
