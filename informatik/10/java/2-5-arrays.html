FesthaltenAufgabe 2: Das Feld

Das Konzept

Ein Feld (englisch Array) speichert eine feste Anzahl von Werten desselben Datentyps unter einem Namen. Jede Zelle hat eine Nummer, den Index. Der erste Index ist 0. So kann eine Schleife alle Zellen nacheinander besuchen.

Auf dem Blatt steht der Code für ein Feld mit acht Zufallszahlen, daneben Lücken für Erklärungen. Übertrage den Code in das Projekt (TODO 2), fülle die Erklärungen und die Tabelle aus und beantworte die Frage zum letzten Index.

Projekt Zufallszahlen

Denkanstoß

Die Schleife soll genau so oft laufen, wie das Feld Zellen hat. Statt die Zahl hinzuschreiben, kannst du zahlenFeld.length verwenden. Dann stimmt die Schleife auch noch, wenn das Feld größer wird.

🔗

UntersuchenArrays mit Referenzen

Ein Feld kann jeden Datentyp aufnehmen, auch Klassen. Dann verweist jede Zelle auf ein Objekt. So lässt sich eine 1:n-Beziehung umsetzen: Eine Mannschaft hat n Spieler, gespeichert in Spieler[] spielerliste. Fülle den Merkkasten und lies die Syntaxübersicht auf dem Blatt.
