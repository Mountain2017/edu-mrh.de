VorhersagenDie Klasse Dreieck

Unten steht eine komplette Klasse und ein Hauptprogramm. Bevor du auf Start klickst: Beschrifte auf dem Blatt die Bausteine der Klasse und schreibe auf, was das Programm ausgibt.

📝 Blatt 2.0 · Einstieg „Implementierung einer Klasse“

Dateien links oben wechseln · ▶ startet das Hauptprogramm

UntersuchenAufgabe 1: Projekt Pizza

📝 Blatt 2.0 · Aufgabe 1

  1. Lies den Code der Klasse Pizza. Zeichne die Klassenkarte und die Objektkarte des Objekts aus dem Hauptprogramm auf das Blatt. Beim Preis lohnt sich ein zweiter Blick in den Konstruktor.
  2. Ergänze die Klassenkarte auf dem Blatt um eine Methode verrechneSchuelerRabatt(), die den Preis um 30 % senkt und den neuen Preis ausgibt. Setze sie dann in Java um und rufe sie im Hauptprogramm auf.

Projekt Pizza

Denkanstoß, falls du hängst

Eine Methode ohne Rückgabewert beginnt mit void. Auf ein Attribut greifst du innerhalb der Klasse direkt mit seinem Namen zu. 30 % weniger heißt: der neue Preis ist 70 % des alten.

VerändernAufgabe 2: Projekt Nagetier

Ein Hamster in einer grafischen Welt. Die Klasse Nagetier erbt von Sprite (Bild, das sich bewegen kann). Die Methode act() wird etwa 30-mal pro Sekunde automatisch aufgerufen.

📝 Blatt 2.0 · Aufgabe 2a

  1. Lies den Ausschnitt auf dem Blatt und beschreibe dort: Was kann passieren, und wann?
  2. Starte das Programm und prüfe deine Beschreibung. Klicke zuerst in das Grafikfenster, damit die Tasten ankommen.
  3. Der Hamster kann nur nach oben und rechts. Ergänze die fehlenden Bewegungen so, dass er alle Körner erreicht.
  4. Bonus: Mach ein Spiel für zwei: ein zweites Nagetier mit anderen Tasten. Was muss dafür an der Klasse anders sein?

Projekt Nagetier

Steuerung: w = hoch, d = rechts

Selbst bauenAufgabe 3: Projekt Auto

Auf dem Blatt steht die Klassenkarte der Klasse Auto. Setze sie in Java um. Im Hauptprogramm warten Tests: Entferne die Kommentarstriche // vor den Testzeilen, sobald der jeweilige Teil fertig ist.

📝 Blatt 2.0 · Aufgabe 3

Projekt Auto

Datei Auto.java ist fast leer – das ist Absicht.
Denkanstoß: Datentypen und Rückgabe

Welche Attribute sind ganze Zahlen, welche Kommazahlen, welche Text? Eine Methode mit Rückgabewert braucht statt void den Datentyp des Ergebnisses und am Ende return …;.

Bonus: Erweitere Auto um eine eigene Methode, z. B. fahre(double km), die den Tank passend leert. Was soll passieren, wenn der Tank nicht reicht?
