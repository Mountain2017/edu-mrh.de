StolpersteinAlles öffentlich?

Jede Klasse darf an allem herumschrauben. Das Hauptprogramm hat leben einfach überschrieben. Der Ball könnte die Punkte ändern, der Block das Leben. Nichts hindert einen Programmfehler oder einen Schummler.
Idee zuerst: Was müsste eine Klasse tun können, damit nur sie selbst ihre Attribute verändert, andere aber trotzdem z. B. einen Punkt melden können? Notiere deinen Vorschlag auf dem Blatt, bevor du weiterliest.

Das Konzept

Mit Zugriffsmodifikatoren legst du fest, wer zugreifen darf: public heißt „jeder“, private heißt „nur innerhalb der eigenen Klasse“. Daten werden so in ihrer Klasse eingekapselt: Datenkapselung. Von außen geht der Zugriff dann nur noch über Methoden, die die Klasse selbst anbietet, meist Getter (gibX()) und Setter (setzeX(…)), die prüfen können, ob eine Änderung sinnvoll ist.
