Weg A: im Browser, ohne Installationder Standard im Unterricht

  • Die Python-Zellen auf den Seiten nutzen Pyodide: echtes Python 3, für den Browser übersetzt (WebAssembly). Es liegt auf edu-mrh.de selbst, beim ersten Ausführen werden etwa 12 MB geladen.
  • Der Code läuft in deinem Browser. Nichts wird an einen Server geschickt, Änderungen am Code werden nur in deinem Browser gespeichert („Zurücksetzen“ stellt den Ausgangscode wieder her).
  • Verfügbar ist die Standardbibliothek (math, random, csv, …) und das Modul ki für Diagramme. numpy und matplotlib gibt es dort nicht, deshalb sind die Netze in einfachem Python mit Schleifen geschrieben. So sieht man jede Rechnung.
  • Funktioniert auf Laptop, Tablet und Handy in aktuellen Browsern; auf älteren Geräten dauert der erste Start etwas länger.

Weg B: am eigenen RechnerWindows oder macOS, etwa 15 Minuten

Variante 1: Visual Studio Code (empfohlen, wenn du VS Code schon kennst)

  1. Python installieren: Windows: im Microsoft Store „Python 3.13“ installieren oder von python.org herunterladen (beim Installieren „Add python.exe to PATH“ ankreuzen). macOS: von python.org herunterladen (oder mit Homebrew: brew install python).
  2. VS Code installieren (code.visualstudio.com), dort die Erweiterungen Python und Jupyter von Microsoft hinzufügen.
  3. Einen Ordner für die KI-Sequenz anlegen, das Notebook hineinlegen und in VS Code öffnen. Oben rechts „Kernel auswählen“ → „Python-Umgebungen“ → „Umgebung erstellen“ (venv).
  4. Im Terminal von VS Code (Menü Terminal → Neues Terminal) die Bibliotheken installieren: 
    pip install numpy matplotlib
  5. Zuerst die Hilfszelle ausführen (Shift + Enter), dann die weiteren Zellen.

Variante 2: Jupyter im Browser des eigenen Rechners

  1. Python installieren wie oben.
  2. Terminal (macOS) bzw. Eingabeaufforderung (Windows) öffnen, in den Ordner wechseln und eine eigene Umgebung anlegen: 
    # macOS
python3 -m venv ki-umgebung
source ki-umgebung/bin/activate
pip install notebook numpy matplotlib
jupyter notebook

# Windows
py -m venv ki-umgebung
ki-umgebung\Scripts\activate
pip install notebook numpy matplotlib
jupyter notebook
  3. Jupyter öffnet sich im Browser (Adresse localhost:8888, läuft nur auf deinem Rechner). Notebook anklicken, Hilfszelle ausführen.
  4. Beim nächsten Mal: Umgebung aktivieren (source …/activate bzw. …\activate), dann jupyter notebook.
Schulrechner: Auf Rechnern ohne Administratorrechte klappt meist Variante 2 mit der Python-Version aus dem Microsoft Store, da sie ins Benutzerverzeichnis installiert. Sonst bleibt Weg A im Browser.

Wenn es hakt

  • python oder pip nicht gefunden: Windows py statt python verwenden, oder Python neu installieren und „Add to PATH“ ankreuzen.
  • ModuleNotFoundError: matplotlib: Das Notebook nutzt eine andere Umgebung als die, in die installiert wurde. In VS Code oben rechts den Kernel der richtigen Umgebung wählen.
  • Daten werden nicht geladen (kein Internet): die CSV-Dateien oben herunterladen und neben das Notebook legen.

Weg C: für Lehrkräfte, eine Umgebung für die ganze KlasseJupyterHub auf einem Schulserver oder JupyterLite ohne Server

JupyterLite: Notebooks im Browser, ohne Server

JupyterLite ist Jupyter, das komplett im Browser läuft (wie die Zellen auf diesen Seiten, ebenfalls mit Pyodide). Es besteht nur aus statischen Dateien und kann auf jedem Webserver der Schule liegen; die Arbeit der Schülerinnen und Schüler bleibt in ihrem Browser. Einrichtung auf einem Rechner mit Python:

pip install jupyterlite-core jupyterlite-pyodide-kernel
mkdir inhalt   # hier die .ipynb-Dateien und CSV-Daten hineinlegen
jupyter lite build --contents inhalt --output-dir ki-lite
# den Ordner ki-lite auf den Webserver kopieren und im Browser öffnen

numpy und matplotlib lassen sich in JupyterLite mit %pip install numpy matplotlib nachladen; die Pakete kommen dann aber von einem fremden Server (Paketverzeichnis von Pyodide). Für den Datenschutz ist es besser, die Pakete beim Bauen mit in den Ordner aufzunehmen (Dokumentation von JupyterLite, „offline“).

JupyterHub auf einem Schulserver

Für eine Umgebung, in der jede Schülerin und jeder Schüler eigene, auf dem Server gespeicherte Notebooks hat, eignet sich The Littlest JupyterHub (TLJH), gedacht für bis zu etwa 100 Nutzende auf einem einzigen Server.

  1. Voraussetzung: ein Server (oder eine virtuelle Maschine) mit aktuellem Ubuntu LTS, mindestens 2 GB Arbeitsspeicher plus etwa 0,5 bis 1 GB je gleichzeitig arbeitender Person, Zugang per SSH, erreichbar im Schulnetz (am besten mit HTTPS).
  2. Installation (als Benutzer mit sudo-Rechten), lehrkraft ist der erste Administrator: 
    curl -L https://tljh.jupyter.org/bootstrap.py | sudo -E python3 - --admin lehrkraft
  3. Im Browser die Adresse des Servers öffnen, als lehrkraft anmelden (beim ersten Mal ein Passwort festlegen), im Terminal von JupyterLab Bibliotheken für alle installieren: 
    sudo -E pip install numpy matplotlib nbgitpuller
  4. Konten für die Klasse im Admin-Bereich anlegen (Control Panel → Admin), am besten mit Pseudonymen statt Klarnamen.
  5. Notebooks verteilen: in den gemeinsamen Ordner legen oder mit nbgitpuller per Link aus einem Repository holen lassen.
  6. HTTPS einrichten (TLJH-Dokumentation: „HTTPS“) und Updates regelmäßig einspielen.

Datenschutz-Checkliste (Schulserver)

  • Schulleitung und Datenschutzbeauftragte oder Datenschutzbeauftragten einbeziehen; Eintrag ins Verzeichnis der Verarbeitungstätigkeiten.
  • Server in der Schule oder beim kommunalen Rechenzentrum (Auftragsverarbeitungsvertrag), nicht bei einem beliebigen Cloud-Anbieter.
  • Pseudonyme Konten, keine Klarnamen nötig; Passwörter nicht per Klassenliste verteilen.
  • Löschkonzept: Konten und Dateien am Ende des Schuljahres löschen.
  • Keine personenbezogenen Daten in Projektdaten (Station P).
  • Die Notebooks laden Daten nur von edu-mrh.de; wer das vermeiden will, legt die CSV-Dateien in den gemeinsamen Ordner.
⚠️

Warum nicht Google Colab?bequem, aber nicht für den Unterricht

Dienste wie Google Colab führen Notebooks auf fremden Servern aus und setzen ein Konto beim Anbieter voraus. Dabei werden Daten über die Nutzung und die hochgeladenen Inhalte verarbeitet, teils außerhalb der EU. Für den Pflichtunterricht darf die Schule das nicht verlangen. Privat kannst du es nutzen, für die Sequenz reichen die Wege A bis C.
