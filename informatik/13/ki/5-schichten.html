Das Zaun-ProblemAufgabe 1: Gerade Zäune, krumme Weiden

Ein Perzeptron ist ein gerader Zaun: Es teilt die Ebene in zwei Hälften. Eine Schäferin will aber eine dreieckige Weide einzäunen und hat nur gerade Zaunstücke. Ein Zaun allein reicht nicht.

Wie viele gerade Zäune (Perzeptronen) braucht die Weide mindestens, und wie entscheidet man dann, ob ein Schaf innen steht?

FesthaltenAufgabe 3: Aufbau eines neuronalen Netzes

Künstliches neuronales Netz (Aufbau)

  • Ein künstliches neuronales Netz besteht aus Neuronen (hier: Perzeptronen), die in Schichten angeordnet sind.
  • Die Eingabeschicht nimmt die Merkmale x1, x2, … auf. Sie rechnet nichts.
  • Die verdeckte Schicht (hidden layer, auch mehrere) liegt dazwischen. Ihre Werte sieht man von außen nicht.
  • Die Ausgabeschicht liefert das Ergebnis, z. B. 1 = innen, 0 = außen.
  • Jede Verbindung hat ein Gewicht, jedes Neuron einen Bias. Alles, was das Netz „weiß“, steckt in diesen Zahlen.

Was die Schichten können: Jedes Neuron der ersten verdeckten Schicht zieht eine gerade Grenze. Ein UND-Neuron (Gewichte 1, Bias −(n − 0,5)) bildet den Schnitt: ein konvexes Gebiet (Streifen, Dreieck, Vieleck). Eine weitere Schicht mit ODER (Bias −0,5) vereinigt mehrere solcher Gebiete. Mit genug Neuronen lässt sich so jede Fläche, im Raum jeder Körper annähern.

Beschrifte auf dem Blatt das Netzbild mit den Fachbegriffen.

Forward Propagation von HandAufgabe 4: das XOR-Netz

Bei der Forward Propagation (Vorwärtsrechnung) werden die Werte Schicht für Schicht von der Eingabe zur Ausgabe berechnet: ① jedes Neuron der verdeckten Schicht aus den Eingaben, ② das Ausgabeneuron aus den Werten der verdeckten Schicht. Hier ein Netz, das XOR berechnet (Eingaben 0 oder 1):

Rechne für alle vier Eingaben: h1 = Stufe(−0,5 + x1 + x2), h2 = Stufe(1,5 − x1 − x2), y = Stufe(−1,5 + h1 + h2). Was berechnen h1 und h2 jeweils für sich?
