Java und AssemblerAufgabe 1: Was der Compiler macht

Die Registermaschine versteht kein Java. Ein Compiler übersetzt jede Anweisung in Maschinenbefehle. Für die Zuweisung links entsteht das Programm rechts. Die Variablen bekommen dabei feste Speicherzellen, den Speicherplan: laenge → 100, breite → 101, umfang → 102.

Java

umfang = 2 * (laenge + breite);

Assembler

LOAD 100     ; ① A = laenge
ADD 101      ; ② A = A + breite
MULI 2       ; ③ A = A * 2
STORE 102    ; ④ umfang = A
HOLD
  1. Aufgabe 1a: Die Länge ist 4, die Breite 3. Was steht nach jedem Befehl im Akkumulator?
  2. Aufgabe 1b: In Java steht die 2 vorne, im Programm wird sie erst in Schritt ③ verwendet. Warum?
  3. Aufgabe 1c: Welcher Teil der Java-Zeile wird zuletzt übersetzt? Woran liegt das?

Übersetzen übenAufgabe 2: vier Zuweisungen

Speicherplan: a → 100, b → 101, x → 102, y → 103, Hilfszelle → 110. Übersetze auf dem Blatt (ohne HOLD):

a)  x = x + 1;
b)  y = 3 * a - b;
c)  y = (a + b) / 2;
d)  y = a - b * 2;
  1. Aufgabe 2a bis 2c: Übersetze nach dem Merkkasten. Prüfe deine Lösung im Übungsfeld unten: Programm eintippen, Startwerte ändern, ⏵ Start.
  2. Aufgabe 2d: Hier funktioniert „von links nach rechts“ nicht: Punkt vor Strich verlangt, dass b * 2 zuerst gerechnet wird. Nutze die Hilfszelle. Das Übungsfeld testet deine Lösung für 2d.

Selbst bauenAufgabe 3: Sekunden umrechnen

Eine Stoppuhr liefert die Zeit in Sekunden, z. B. 4000. Angezeigt werden soll „1 h 6 min 40 s“. Speicherplan: gesamt → 100, stunden → 101, minuten → 102, sekunden → 103.

  1. Aufgabe 3a: Schreibe auf dem Blatt die drei Java-Zuweisungen für stunden, minuten und sekunden. Nutze / und %.
  2. Aufgabe 3b: Übersetze sie in Assembler und teste im Simulator.
Für Schnelle: Wechselgeld. In Zelle 100 steht ein Betrag in Cent (z. B. 385). Berechne, wie viele 2-€-Münzen (101), 1-€-Münzen (102), 50-ct-Münzen (103) und wie viel Restbetrag in Cent (104) herauskommen. Im Simulator kannst du frei programmieren.

RückwärtsAufgabe 4: Welche Zuweisung steckt darin?

Speicherplan: f (Temperatur in Grad Fahrenheit) → 100, celsius → 101.

LOAD 100
SUBI 32
MULI 5
DIVI 9
STORE 101
HOLD
  1. Aufgabe 4a: Schreibe die Java-Zuweisung, die der Compiler übersetzt hat. Achte auf Klammern.
  2. Aufgabe 4b: Was ergibt sich für f = 212 und für f = 100? Prüfe im Simulator.

🔀 Entscheidungen

Bisher wird jeder Befehl genau einmal ausgeführt, von oben nach unten. In 2.4 lernst du Sprungbefehle kennen: Damit setzt die Maschine eine if-Anweisung um.

⚙️ Compiler

Ein echter Compiler macht genau das, was du hier tust: Er legt einen Speicherplan an, zerlegt Terme nach der Rechenreihenfolge und optimiert, wo es geht. Die Regeln, welche Programme überhaupt gültig sind, kennst du aus Kapitel 1 (Grammatik, EBNF).
