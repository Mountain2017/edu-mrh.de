2.5 Schleifen in Assembler

Funktionsweise eines Rechners · Informatik 13 · 3 Stunden

VorhersagenAufgabe 1: Die Summe 1 + 2 + … + n

Speicherplan: n → 100, i → 101, summe → 102. Neu ist der Sprung in Zelle 13: Er führt zurück.

Struktogramm

summe = 0
i = 1
solange i ≤ n
summe = summe + i
i = i + 1

Assembler

        LOADI 0
        STORE 102     ; summe = 0
        LOADI 1
        STORE 101     ; i = 1
kopf:   LOAD 101
        CMP 100
        JGT ende
        LOAD 102
        ADD 101
        STORE 102
        LOAD 101
        ADDI 1
        STORE 101
        JMP kopf
ende:   HOLD
  1. Aufgabe 1a: Fülle für n = 3 die Tabelle auf dem Blatt aus: Welchen Wert hat i beim Vergleich in Zelle 5, springt JGT in Zelle 6, und was steht danach in summe?
  2. Aufgabe 1b: Wie oft wird der Befehl in Zelle 4 für ein beliebiges n ausgeführt?
  3. Prüfe mit dem Simulator. Mit „Protokoll“ siehst du jeden Durchlauf, Sprünge sind lila markiert.

📝 Blatt 2.5 · Aufgabe 1

📝

FesthaltenMerkkasten „Wiederholung mit Bedingung“

Ergänze den Merkkasten auf dem Blatt. Leitfragen: Wo steht die Bedingung, vor oder nach dem Rumpf? Woran erkennt man eine Schleife im Assemblerprogramm? Was muss im Rumpf passieren, damit die Schleife irgendwann endet?

Java

summe = 0;
i = 1;
while (i <= n) {          // ①
   summe = summe + i;     // ②
   i = i + 1;             // ③
}                         // ④

Assembler

kopf:   LOAD 101      ; ① Bedingung prüfen
        CMP 100
        JGT ende      ;    umgekehrt: i > n -> raus
        LOAD 102      ; ② Rumpf
        ADD 101
        STORE 102
        LOAD 101      ; ③ Zähler erhöhen
        ADDI 1
        STORE 101
        JMP kopf      ; ④ zurück zum Kopf
ende:   HOLD

VerändernAufgabe 2: Multiplizieren ohne MUL

Frühe Prozessoren (z. B. der 6502 im Commodore 64) hatten keinen Multiplikationsbefehl. Multiplizieren heißt dann: oft genug addieren. a · b = a + a + … + a (b-mal). Speicherplan: a → 100, b → 101, produkt → 102, i → 103.

Struktogramm

produkt = 0
i = 0
solange i < b
produkt = produkt + a
i = i + 1

Selbst bauenAufgabe 3: Die Fakultät

n! = 1 · 2 · 3 · … · n, z. B. 5! = 120. Per Definition ist 0! = 1. Speicherplan: n → 100, f → 101 (Ergebnis), i → 102.

  1. Aufgabe 3a: Zeichne auf dem Blatt das Struktogramm.
  2. Aufgabe 3b: Programmiere und teste im Simulator.
  3. Aufgabe 3c: Probiere n = 7 und n = 8. Ab welchem n ist das Ergebnis falsch? Woran erkennst du das, ohne nachzurechnen?
Für Profis: ggT nach Euklid. Solange a ≠ b: Ist a > b, wird a = a − b, sonst b = b − a. Am Ende steht der größte gemeinsame Teiler in a. Eine Schleife mit einer Verzweigung darin.
solange a ≠ b
a > bwahrfalsch
a = a − b
b = b − a

LaufzeitAufgabe 4: Schleife oder Formel?

Der junge Carl Friedrich Gauß soll die Zahlen von 1 bis 100 addiert haben, indem er Paare bildete: 1 + 100, 2 + 99, … Das ergibt die Formel summe = n * (n + 1) / 2.
