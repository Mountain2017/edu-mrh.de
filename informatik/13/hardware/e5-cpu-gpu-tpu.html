Wer macht was?Aufgabe 1: Drei Arten von Prozessoren

In einem Smartphone oder Laptop stecken heute mindestens drei Arten von Rechenwerken auf einem Chip: die CPU (central processing unit, Universalprozessor), die GPU (graphics processing unit, Grafikprozessor) und eine NPU (neural processing unit, KI-Beschleuniger; Googles Rechenzentrums-Version heißt TPU, tensor processing unit). Tippe, wer welche Aufgabe übernimmt. Am Ende der Station weißt du, warum.

  • 🗂️Das Betriebssystem entscheidet, welche App als Nächstes Rechenzeit bekommt.Viele Entscheidungen, Verzweigungen, wenig gleichartige Daten: typische CPU-Arbeit.
  • 🎮Ein 3D-Spiel berechnet für jedes der 8 Millionen Pixel (4K) 60-mal pro Sekunde die Farbe.Millionen gleichartige, voneinander unabhängige Rechnungen: das, wofür GPUs erfunden wurden.
  • 📸Die Kamera-App erkennt in Echtzeit Gesichter und stellt auf sie scharf.Ein neuronales Netz, also vor allem Matrixmultiplikationen mit wenig Genauigkeit: Dafür ist die NPU gebaut, sparsamer als die GPU.
  • 🌐Der Browser führt das JavaScript einer Webseite aus.Ein gewöhnliches Programm mit vielen Sprüngen und Funktionsaufrufen, Schritt für Schritt: CPU.
  • 🧠Ein Forschungslabor trainiert ein großes Sprachmodell über Wochen auf Tausenden Chips.Das läuft heute meist auf großen Rechenzentrums-GPUs (z. B. von Nvidia), bei Google auf TPUs. Beides wäre richtig; GPUs sind am verbreitetsten.
🧠

Die CPUWenige, sehr schlaue Kerne

Eine CPU hat heute meist 4 bis 24 Kerne. Jeder Kern ist eine vollständige Registermaschine mit eigenem Steuerwerk. Aber nur ein kleiner Teil der Chipfläche rechnet wirklich. Der Rest sorgt dafür, dass ein einzelnes Programm möglichst schnell vorankommt:

  • Große Caches halten Daten nah am Rechenwerk (Von-Neumann-Flaschenhals, 2.1).
  • Pipeline: Während ein Befehl ausgeführt wird, wird der nächste schon dekodiert und der übernächste geholt.
  • Sprungvorhersage: Bei JLT rät das Steuerwerk, ob gesprungen wird, und arbeitet schon mal weiter (meist liegt es richtig).
  • Umsortieren: Befehle, die nicht voneinander abhängen, werden in anderer Reihenfolge oder gleichzeitig ausgeführt.
  • Hoher Takt: 3 bis 6 GHz.

Die GPUEin Steuerwerk, viele Rechenwerke

Grafikprozessoren wurden für Bilder erfunden: Jedes Pixel wird mit demselben kleinen Programm (Shader) berechnet, nur mit anderen Daten. Wozu also jedem Rechenwerk ein eigenes, teures Steuerwerk geben? Eine GPU fasst 32 Rechenwerke zu einer Gruppe zusammen, die denselben Befehl gleichzeitig auf 32 verschiedene Daten anwendet. Ein Steuerwerk holt und dekodiert, 32 ALUs rechnen.

  • Eine große Grafikkarte (z. B. Nvidia RTX 4090) hat über 16 000 solcher einfachen Rechenwerke.
  • Takt nur etwa 2 bis 2,5 GHz, kaum Vorhersage, kleine Caches.
  • Muss eine Gruppe auf den Speicher warten, schaltet die GPU blitzschnell auf eine andere Gruppe um, statt zu warten.
  • Sehr breiter Speicheranschluss: mehrere Terabyte pro Sekunde (eine CPU: etwa 0,1 TB/s).

Fachbegriff: SIMD (single instruction, multiple data), bei Nvidia SIMT (… multiple threads).

Das RennenAufgabe 2: Wer ist schneller?

Eine CPU mit 8 starken Kernen tritt gegen eine GPU mit 512 einfachen Rechenwerken an. Ein CPU-Kern schafft einen Rechenschritt in 1 Zeiteinheit, ein GPU-Rechenwerk braucht 4 (niedriger Takt, keine Tricks). Sage vorher, wer bei welcher Aufgabe gewinnt und mit welchem Abstand. Dann starte.

  1. Berechne die Zeiten beider Aufgaben selbst und vergleiche mit der Simulation.
  2. Ordne zu: Videos umrechnen, ein Schachprogramm, das einen Zug nach dem anderen durchdenkt, Wettervorhersage (Millionen Gitterpunkte), einen Text auf Rechtschreibung prüfen, Passwörter durchprobieren.
  3. Ein GPU-Programm enthält if (x < 0) { … } else { … }. In einer Gruppe von 32 ist x bei 16 Pixeln negativ. Was muss die Gruppe tun, wenn alle 32 immer denselben Befehl ausführen?

FesthaltenLatenz und Durchsatz

Merkkasten: CPU und GPU

  • Latenz: Wie lange dauert eine Aufgabe? Durchsatz: Wie viele Aufgaben werden pro Sekunde fertig?
  • Die CPU ist auf kurze Latenz gebaut: wenige Kerne, jeder mit großem Steuerwerk, Caches und hohem Takt. Sie ist gut bei verzweigten, voneinander abhängigen Schritten.
  • Die GPU ist auf hohen Durchsatz gebaut: ein Steuerwerk für viele einfache Rechenwerke, die denselben Befehl auf verschiedene Daten anwenden (SIMD). Sie ist gut bei vielen gleichartigen, unabhängigen Rechnungen.
  • Beide bestehen aus denselben Bausteinen (Transistoren, Gatter, Addierer, Register); verschieden ist nur, wie viele davon wofür verwendet werden.

KI-ChipsAufgabe 3: Das systolische Array

Ein neuronales Netz rechnet fast nur eines: Matrixmultiplikationen, also sehr viele „multipliziere und addiere zur Summe“ (MAC: multiply-accumulate). Google entwickelte dafür ab 2015 die TPU. Ihr Kern ist ein Feld aus 256 × 256 = 65 536 einfachen Multiplizier-Addier-Zellen ohne eigenes Steuerwerk. Die Daten werden nicht für jede Rechnung aus dem Speicher geholt, sondern fließen von Zelle zu Zelle, im Takt, wie das Blut im Herzschlag (griechisch systole). Hier ein Feld aus 3 × 3 Zellen, das C = A · B berechnet:

  1. Gehe Takt für Takt durch. Warum kommen die Zeilen von A und die Spalten von B schräg versetzt ins Feld?
  2. Wie viele Takte braucht ein n × n-Feld für zwei n × n-Matrizen? Prüfe deine Formel für n = 3.
  3. Wie oft wird jede Zahl aus A aus dem Speicher geladen? Wie oft wäre es bei einer Registermaschine, die C Zelle für Zelle mit LOAD, MUL, ADD berechnet?

Rechnen ist billig, Daten bewegen ist teuer

Energie für einzelne Vorgänge in einem Chip (Messwerte für 45-nm-Technik, nach M. Horowitz 2014; heutige Werte sind kleiner, die Verhältnisse ähnlich):

VorgangEnergieim Vergleich

32-Bit-Ganzzahl addieren0,1 pJ3
8-Bit-Ganzzahl multiplizieren0,2 pJ7

32 Bit aus kleinem Cache lesen5 pJ170

Deshalb rechnen KI-Chips mit wenig Genauigkeit (8 Bit oder 16 Bit statt 32 Bit): Für ein neuronales Netz ist es fast egal, ob ein Gewicht 0,4732 oder 0,47 ist, aber die Rechenwerke werden viel kleiner und sparsamer, und es passen doppelt bis viermal so viele Zahlen durch dieselbe Leitung.

Der VergleichAufgabe 4: Spezialisierung

🧠 CPU

  • 4–24 starke Kerne, 3–6 GHz
  • großes Steuerwerk je Kern, große Caches
  • Ziel: kurze Latenz
  • stark bei: Verzweigungen, Betriebssystem, gewöhnlichen Programmen
  • jeder Algorithmus läuft (Universalrechner)

🎮 GPU

  • Tausende einfache Rechenwerke, ~2 GHz
  • ein Steuerwerk für je 32 Rechenwerke (SIMD)
  • Ziel: hoher Durchsatz
  • stark bei: Grafik, Simulation, KI-Training
  • schwach bei Verzweigungen und abhängigen Schritten

🤖 TPU / NPU

  • riesiges Feld aus Multiplizier-Addier-Zellen
  • kaum Steuerwerk, Daten fließen durch das Feld
  • Ziel: Matrixmultiplikation pro Watt
  • stark bei: neuronalen Netzen, wenig Genauigkeit
  • kann fast nichts anderes
  1. Je spezialisierter ein Chip, desto schneller und sparsamer ist er bei seiner Aufgabe. Was ist der Preis dafür?
  2. Ordne ein: Wo steht die Registermaschine aus Lernbereich 2? Und ein Taschenrechner-Chip?
