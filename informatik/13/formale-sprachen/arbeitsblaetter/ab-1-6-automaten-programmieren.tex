\abtitel{1.6}{Endliche Automaten programmieren}

In 1.5 stand der Automat in einer \textbf{Übergangstabelle}, also in Daten. Hier steckt er direkt im
\textbf{Programmcode}. Beispiel: Ein Compiler muss Namen (Bezeichner) wie \code{zahl2} erkennen, vereinfacht:
\code{Bezeichner = Buchstabe \{Buchstabe | Ziffer\}.}

\begin{aufgabe}[Code lesen: der Bezeichner-Automat]{1}

\vspace{0pt}
\begin{java}[basicstyle=\ttfamily\fontsize{8.6}{10.2}\selectfont,numbers=left,xleftmargin=5mm,framexleftmargin=1mm]
public void zustandWechseln(char zeichen) {
   switch (zustand) {
      case 0:
         if (Character.isLetter(zeichen)) {
            zustand = 1;
         } else {
            zustand = ZF;
         }
         break;
      case 1:
         if (Character.isLetterOrDigit(zeichen)) {
            zustand = 1;
         } else {
            zustand = ZF;
         }
         break;
      default:
         zustand = ZF;
   }
}
public boolean istEndzustand() {
   return zustand == 1;
}
\end{java}

\begin{merke}[Einen Automaten als Code programmieren]
\lueckentext
\textbf{Zustand:} Das Attribut \code{zustand} merkt sich, wo der Automat gerade steht (0 für Z0, 1 für Z1, …).\\
\textbf{Übergänge:} \code{zustandWechseln(zeichen)} unterscheidet zuerst nach dem \lsg[5.25cm]{aktuellen Zustand} (\code{switch}: je Zustand ein \code{case}), dann nach dem \lsg[5.25cm]{gelesenen Zeichen} (\code{if}). Jeder \lsg[5.25cm]{Pfeil} wird genau eine Anweisung \code{zustand = …;}\\
\textbf{Kein passender Pfeil:} Der \code{else}-Zweig führt in den \lsg[5.25cm]{Fangzustand ZF}, der \code{default}-Zweig sorgt dafür, dass ZF \lsg[5.25cm]{nie verlassen wird}.\\
\textbf{Endzustände:} \code{istEndzustand()} vergleicht \code{zustand} mit allen \lsg[5.25cm]{Endzuständen}.\\[1mm]
\begin{minipage}[t]{0.47\linewidth}
\vspace{0pt}
{\small Gegeben: abstrakte Oberklasse \code{DEA}}
\begin{java}[basicstyle=\ttfamily\fontsize{8.6}{10.2}\selectfont,aboveskip=0.5mm,belowskip=0mm]
public boolean pruefe(String wort) {
   zustand = 0;                              // (*\nr{1}*)
   for (int i = 0; i < wort.length(); i++) { // (*\nr{3}*)
      zustandWechseln(wort.charAt(i));       // (*\nr{2}*)
   }
   return istEndzustand();                   // (*\nr{4}*)
}
\end{java}
\end{minipage}\hfill
\begin{minipage}[t]{0.5\linewidth}
\vspace{4mm}\lueckentext
\code{pruefe} ist für \lsg[5.25cm]{alle Automaten gleich} und steht deshalb in der Oberklasse \code{DEA}. Jede Unterklasse legt nur die \lsg[3.9cm]{Übergänge} und die \lsg[3.9cm]{Endzustände} fest.
\end{minipage}
\end{merke}
