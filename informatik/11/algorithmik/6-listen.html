VorhersagenVon der Schachtel zum Regal

In Station 2 war eine Variable eine beschriftete Schachtel für genau einen Wert. Was aber, wenn du die Klausurpunkte der ganzen Klasse speichern willst? 25 Variablen punkte1, punkte2, … – und für jede neue Schülerin das Programm umschreiben? Eine Liste ist eine Variable mit einem ganzen Regal voller nummerierter Fächer.

AusprobierenVergleichen – und der Liste zusehen

  1. Öffne die Vorlage: ▶ Vorlage in Snap! öffnen
  2. Starte A, B, C, D (⚑, b, s, z). Beobachte dabei die Listen-Anzeigen auf der Bühne: Snap! zeigt jede Liste als Tabelle mit Nummern links – genau das Regal von oben.
  3. Skript B läuft langsam: Die Figur sagt zuerst, was gleich passiert. Schau, wie sich die Nummern der anderen Elemente verändern.
  4. Drücke e und gib ein paar Namen ein (Ende mit fertig). Die Liste namen wächst mit jeder Eingabe.
  5. Klicke im Skriptbereich direkt auf einen Block wie Element 2 von einkauf: Snap! zeigt das Ergebnis in einer Sprechblase.

UntersuchenStellen, Operationen, Durchlaufen

  1. Skript B: Was passiert mit den Nummern von Brot, Äpfeln und Käse, wenn vorne etwas entfernt wird? Und wenn vorne etwas eingefügt wird? Trag den Zustand nach jedem Schritt ins Arbeitsblatt ein.
  2. Vergleiche entferne … mit Element … von …. Welcher Block verändert die Liste, welcher fragt nur nach? Woran erkennst du das an der Form (Station 5)?
  3. Skript D: Füge in klasse einen sechsten Namen hinzu. Musst du sonst noch etwas ändern? Warum steht dort Länge von klasse und nicht einfach 5?
  4. Skript C: Wie oft läuft die Schleife? Welchen Wert hat Element im 3. Durchgang, welchen summe danach? Prüfe mit der Durchlauf-Tafel unten.
  5. Ein Text ist auch eine Art Liste – aus Zeichen. Klicke auf Zeichen 2 von Brot und Länge von Brot (Palette Operatoren). Was ist gleich wie bei Listen?

🔁 Durchlauf-Tafel: „für jedes Element“ in Zeitlupe

Die Schleife für jedes Element von punkte holt sich der Reihe nach jedes Fach in die Variable Element und führt dann den Inhalt der Klammer aus. Klicke dich durch Skript C:

Das steckt dahinter

Liste
Eine Folge von Werten in fester Reihenfolge unter einem Namen. Die einzelnen Werte heißen Elemente. Die Liste kann wachsen und schrumpfen, sie kann auch leer sein.
Stelle (Index)
Die Nummer eines Elements. In Snap! hat das erste Element die Stelle 1. Wird vorne etwas eingefügt oder entfernt, bekommen alle Elemente dahinter eine neue Nummer.
Länge
Die Anzahl der Elemente. Das letzte Element steht an Stelle Länge. Wer mit der Länge statt mit einer festen Zahl rechnet, schreibt Programme, die mit jeder Liste funktionieren.
Datentyp Liste
Wie bei Zahl, Zeichenkette und Wahrheitswert legt der Datentyp fest, welche Werte es gibt und welche Operationen damit möglich sind. Werte: endliche Folgen von Elementen (Zahlen, Texte, sogar Listen). Operationen: erzeugen (Liste), nachfragen (Element, Länge, enthält, Index von) und verändern (füge hinzu, füge ein, ersetze, entferne).
Durchlaufen
Mit für jedes Element von liste wird jedes Element genau einmal bearbeitet – egal wie lang die Liste ist. Typische Muster: Summe bilden, zählen, das Größte suchen, etwas finden.

🧪 Listen-Labor: jede Operation zum Anfassen

Hier kannst du alle Listen-Operationen ausprobieren, ohne etwas kaputt zu machen. Wähle einen Wert und eine Stelle und klicke auf einen Block. Grün = neu, gelb = hat eine neue Nummer bekommen, blau = wurde gelesen.

Forscherauftrag: Was passiert bei Element 7, wenn die Liste nur 4 Elemente hat? Füge etwas an Stelle 1 ein und dann an Stelle Länge + 1. Welche Elemente werden gelb – und warum?

⚙️ Unter der Haube: Wie speichert der Computer eine Liste?

Bisher ging es darum, was eine Liste kann. Das ist die Idee des Datentyps. Wie der Computer sie im Speicher ablegt, ist eine zweite Frage. Der Speicher ist eine riesige Reihe nummerierter Speicherzellen (Adressen). Es gibt zwei klassische Lösungen. Schalte im Labor zwischen Fächer und Kette um und vergleiche den Aufwand.

🗄️ Feld (Array): Fächer nebeneinander

Alle Elemente liegen direkt hintereinander im Speicher, wie Schließfächer in einem Gang. Kennt man den Anfang, kann man jedes Fach sofort ausrechnen: Fach 4 liegt 3 Fächer hinter dem Anfang.

100Milch101Brot102Äpfel103Käse104frei

Nachteil: Wer vorne einfügt, muss alle anderen Elemente ein Fach weiterrücken.

🔗 Verkettete Liste: eine Schnitzeljagd

Die Elemente liegen irgendwo im Speicher. Jedes trägt einen Zettel mit der Adresse des nächsten (einen Zeiger). Man kennt nur den Anfang.

100Milch ➜207…154Äpfel ➜311207Brot ➜154311Käse ∅

Einfügen geht schnell: nur zwei Zettel ändern. Aber um Element 4 zu finden, muss man der Kette von vorne folgen.

🧍🧍🧍 Spielt es nach (5 Freiwillige, 10 Minuten)

  1. Menschen-Feld: Stellt euch auf nummerierte Plätze 1–5 direkt nebeneinander, jede Person hält einen Zettel mit einem Wort. Die Klasse ruft Befehle: „Element 4?“ – „Füge Lea als 2 ein!“ – „Entferne 1!“. Zählt, wie viele Personen jeweils umziehen müssen.
  2. Menschen-Kette: Verteilt euch kreuz und quer im Raum. Jede Person zeigt auf die nächste, die Lehrkraft kennt nur Person 1. Dieselben Befehle: Wer muss sich jetzt bewegen? Wie findet ihr Element 4?
  3. Besprecht: Welche Speicherart ist besser für eine Playlist, in der man oft springt? Welche für eine Warteschlange, bei der ständig vorne jemand drankommt?

Snap! nimmt dir diese Entscheidung ab und wandelt intern sogar je nach Bedarf um. In anderen Sprachen wählst du selbst: In Java gibt es ArrayList (Feld) und LinkedList (Kette). Dort hat das erste Element übrigens den Index 0, weil der Index angibt, wie viele Fächer man vom Anfang aus weitergehen muss.

✏️

VerändernGezielt umbauen

  1. Skript A: Die Figur soll zusätzlich das letzte Element sagen – egal, wie viele Dinge auf der Liste stehen. Teste, indem du ein weiteres füge … hinzu einbaust.
  2. Skript C: Die Figur soll auch das beste Ergebnis (die größte Zahl) nennen. Überlege zuerst ohne Snap!: Wie findest du in einer Reihe von Zahlenkarten die größte, wenn du immer nur eine Karte gleichzeitig ansehen darfst?
  3. Skript D: Jede Person soll genau einmal drankommen, bis alle durch sind (z. B. für die Reihenfolge von Referaten).
Lösungshinweis

1: Das letzte Element steht an Stelle Länge von einkauf – dieser Block passt in die Lücke von Element … von. 2: Merke dir in einer Variable max zuerst Element 1. Vergleiche in für jedes jedes Element mit max; ist es größer, wird es das neue max. 3: wiederhole bis Länge von klasse = 0: zufällige Stelle ziehen, Namen sagen, dann entferne nr aus klasse. Lösungsprojekt öffnen.
