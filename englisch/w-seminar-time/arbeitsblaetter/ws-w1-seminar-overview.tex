\begin{minipage}[t]{0.49\linewidth}\vspace{0pt}
\begin{wsbox}[height=62mm]{3}{The Seminararbeit in brief}
\begin{itemize}[itemsep=0.6mm]
\item written \textbf{in English}, the Prüfungsgespräch too
\item about \textbf{10–15 pages} of text (without title page, contents, works cited, appendix)
\item you \textbf{put something to the test}: survey, experiment, measurement or systematic text analysis – and evaluate your own data
\item sources cited in \textbf{MLA style}
\item signed \textbf{declaration of authorship} + \textbf{AI log}
\item format unless announced otherwise: 12\,pt, line spacing 1.5, margins 2.5\,cm
\item internal point of reference: \textbf{5000 words}
\end{itemize}
\end{wsbox}
\end{minipage}

% ------------------------------------------------------------------ 4
\begin{wsbox}{4}{AI, tools and your own voice}
\begin{minipage}[t]{0.63\linewidth}\vspace{0pt}
AI tools are part of real research – use them, but \textbf{openly}.
\begin{itemize}[itemsep=0.5mm]
\item Keep an \textbf{AI log}: date, tool, what you asked, what you used – \emph{including language polishing}.
\item Never trust an AI reference – check that every source exists.
\item \textbf{Snapshots, about every 4 weeks:} hand in your current state – dump, outline or draft, however rough.
\item \textbf{Planned:} a supervised writing session – if you want your language graded in full, the text you write there is your reference.
\end{itemize}
\end{minipage}\hfill

\begin{itemize}[itemsep=0.4mm]
\item \textbf{Sync is not a backup}: delete or overwrite a file in a synced folder and the mistake syncs too. Learn where the \textbf{version history} is (OneDrive, Overleaf).
\item Save milestones as new versions:\newline \texttt{\footnotesize 2027-03-12\_seminararbeit\_v03.docx}\newline – never just \emph{final\_final2.docx}.
\item A lost file does not move the deadline.
\end{itemize}
